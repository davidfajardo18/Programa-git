# SICIT - GA7-220501096-AA2-EV01

Aprendiz: David Fajardo Esteban

Proyecto PHP orientado a objetos basado en el Modelo Base suministrado por el instructor.

## Clases implementadas
- Medico
- Consultorio
- Medicamento

Cada clase contiene atributos privados, getters/setters y operaciones CRUD de inserción, consulta, actualización y eliminación.

## Tecnologías
PHP, MySQL/MariaDB, mysqli, HTML5, CSS3, Git y GitHub.

## Ejecución con XAMPP
1. Copiar el proyecto dentro de htdocs.
2. Iniciar Apache y MySQL.
3. Importar database/centromedico.sql desde phpMyAdmin.
4. Abrir public/index.php desde localhost.
