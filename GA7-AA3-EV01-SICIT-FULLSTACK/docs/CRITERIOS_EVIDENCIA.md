# Correspondencia con los criterios de la evidencia

| Criterio | Implementación |
|---|---|
| Considerar artefactos previos | Se reutiliza el frontend Centro Médico/SICIT de la evidencia anterior. |
| Código con comentarios | PHP, JavaScript y SQL incluyen comentarios explicativos. |
| Estándares de codificación | Nombres consistentes, responsabilidades separadas y consultas preparadas. |
| Herramienta de versionamiento | Proyecto preparado para Git/GitHub y enlace incluido. |
| Framework de diseño | Bootstrap 5.3.3. |
| Módulo web funcional | Pacientes, Médicos, Citas, Consultorios, Usuarios y Roles. |
| Persistencia | MySQL mediante PDO. |
| CRUD | GET/POST/PUT/DELETE por módulo. |
| Video expositivo | Se incluye guion paso a paso en `docs/GUION_VIDEO.md`. |

## Nota sobre la tecnología de backend

La guía escrita menciona frameworks Java. Sin embargo, el material de apoyo suministrado por el profesor
en la carpeta de clase incluye específicamente un flujo para transformar el frontend existente en una
aplicación **PHP + MySQL + JavaScript**, con conexión PDO, endpoints PHP, `fetch()` y CRUD real. Esta
entrega sigue ese material práctico y conserva Bootstrap como framework de diseño.
